# Student CRUD App - React Native (Frontend)

This is the **React Native frontend** for a Student Management System that allows users to **create, read, update, and delete (CRUD) student records**. It communicates with a Java Spring Boot backend API.

## Features

- List all students
- View student details
- Add new students
- Update existing students
- Delete students with confirmation
- Navigation with React Navigation

## Tech Stack

- React Native
- TypeScript
- React Navigation
- Fetch API / Axios for API calls
- Functional Components

## Getting Started

### Prerequisites

- Node.js >= 22.x
- npm or yarn
- React Native CLI or Expo CLI
- Android Studio / Xcode (for mobile simulators)

### Installation

```bash
# Clone the repository
git clone <frontend-repo-url>
cd <frontend-folder>

# Install dependencies
npm install
# or
yarn install
